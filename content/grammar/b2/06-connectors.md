## Cause

| Connector                | Nuance                        | Example                                 |
| ------------------------ | ----------------------------- | --------------------------------------- |
| parce que                | neutral, answers “pourquoi ?” | Je reste parce que je suis malade.      |
| puisque                  | the cause is obvious / known  | Puisque tu es là, aide-moi.             |
| comme                    | at the start of the sentence  | Comme il pleuvait, on est restés.       |
| car                      | formal, written, never first  | Il est absent, car il est malade.       |
| grâce à + noun           | positive cause                | Grâce à toi, j’ai réussi.               |
| à cause de + noun        | negative cause                | À cause de la grève, j’ai raté l’avion. |
| étant donné que / vu que | given that                    | Vu qu’il est tard, rentrons.            |

## Consequence

| Connector                                | Example                                           |
| ---------------------------------------- | ------------------------------------------------- |
| donc, alors                              | Il pleut, donc je prends un parapluie.            |
| c’est pourquoi                           | Je suis fatigué, c’est pourquoi je reste.         |
| si bien que, de sorte que (+ indicative) | Il a trop mangé, si bien qu’il est malade.        |
| si / tellement … que                     | Il fait si chaud qu’on ne peut pas dormir.        |
| par conséquent                           | Le vol est annulé ; par conséquent, nous restons. |

## Concession & opposition

| Connector                                 | Construction           | Example                                      |
| ----------------------------------------- | ---------------------- | -------------------------------------------- |
| bien que, quoique                         | + subjunctive          | Bien qu’il soit riche, il est malheureux.    |
| malgré                                    | + noun                 | Malgré la pluie, on est sortis.              |
| pourtant, cependant, néanmoins, toutefois | adverbs                | Il est riche ; pourtant, il est malheureux.  |
| même si                                   | + indicative           | Même s’il pleut, je viendrai.                |
| alors que, tandis que                     | contrast, + indicative | Il aime le thé alors que je préfère le café. |
| avoir beau + infinitive                   | no matter how much     | J’ai beau essayer, je n’y arrive pas.        |

## Exercises

### mcq
- prompt: Thanks to your help, I succeeded.
- [ ] À cause de ton aide, j’ai réussi.
- [x] Grâce à ton aide, j’ai réussi.
- [ ] Parce que ton aide, j’ai réussi.
- explain: Positive cause + noun → grâce à.

### cloze
- sentence: ___ tu es là, tu peux m’aider.
- answer: Puisque
- answer: Comme
- en: Since you’re here, you can help me.
- explain: Obvious cause → puisque (comme also works at the start).

### cloze
- sentence: ___ la neige, le train est en retard.
- answer: À cause de
- en: Because of the snow, the train is late.
- explain: Negative cause + noun.

### cloze
- sentence: Bien qu’il ___ malade, il travaille.
- hint: être
- answer: soit
- en: Although he’s ill, he’s working.
- explain: bien que + subjunctive.

### cloze
- sentence: ___ la pluie, nous sommes sortis.
- answer: Malgré
- en: Despite the rain, we went out.
- explain: malgré + noun.

### cloze
- sentence: Même s’il ___, je viendrai.
- hint: pleuvoir
- answer: pleut
- en: Even if it rains, I’ll come.
- explain: même si + indicative (present).

### cloze
- sentence: Il fait ___ froid qu’on reste à la maison.
- answer: si
- answer: tellement
- en: It’s so cold that we’re staying home.
- explain: si / tellement + adjective + que.

### cloze
- sentence: J’ai ___ chercher, je ne trouve pas mes clés.
- answer: beau
- en: No matter how hard I look, I can’t find my keys.
- explain: avoir beau + infinitive.

### mcq
- prompt: Which connector can’t start a sentence?
- [ ] comme
- [ ] puisque
- [x] car
- [ ] étant donné que
- explain: car always comes after the main clause.

### mcq
- prompt: He likes the city, whereas she prefers the countryside.
- [ ] Il aime la ville, bien qu’elle préfère la campagne.
- [x] Il aime la ville, alors qu’elle préfère la campagne.
- [ ] Il aime la ville, malgré elle préfère la campagne.
- explain: Contrast between two facts → alors que / tandis que.

### translate
- en: He is rich; however, he is unhappy.
- answer: Il est riche ; pourtant, il est malheureux
- answer: Il est riche ; cependant, il est malheureux
- answer: Il est riche, pourtant il est malheureux
- answer: Il est riche mais il est malheureux
- answer: Il est riche ; néanmoins, il est malheureux
- answer: Il est riche ; toutefois, il est malheureux
- answer: Il est riche, cependant il est malheureux
