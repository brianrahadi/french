## The forms

|                                     | Masc. sg. | Fem. sg.    | Masc. pl. | Fem. pl.   |
| ----------------------------------- | --------- | ----------- | --------- | ---------- |
| (preposition +)                     | lequel    | laquelle    | lesquels  | lesquelles |
| à +                                 | auquel    | à laquelle  | auxquels  | auxquelles |
| de + (after a compound preposition) | duquel    | de laquelle | desquels  | desquelles |

Use lequel after a **preposition** when referring to a **thing**. It agrees with the noun it replaces.

## Examples

- La table sur laquelle j’ai posé mes clés. | The table on which I put my keys.
- Les raisons pour lesquelles je pars. | The reasons why (for which) I’m leaving.
- Le projet auquel je travaille. | The project I’m working on (travailler à).
- Le parc près duquel j’habite. | The park near which I live (près de).

> [!TIP]
> For **people**, prefer **qui** after a preposition: *la personne **avec qui** je travaille*, *l’ami **à qui** j’ai écrit*.

> [!WARNING]
> With plain **de** (parler de, avoir besoin de), use **dont**, not duquel. duquel is for compound prepositions: près de, à côté de, au milieu de, en face de…

## Exercises

### cloze
- sentence: Voici le stylo avec ___ j’écris.
- answer: lequel
- en: Here is the pen I write with.
- explain: stylo (m. sg.) after avec → lequel.

### cloze
- sentence: La raison pour ___ je suis venu est simple.
- answer: laquelle
- en: The reason why I came is simple.
- explain: raison (f. sg.) → laquelle.

### cloze
- sentence: Le concours ___ je participe est difficile.
- answer: auquel
- en: The competition I’m taking part in is difficult.
- explain: participer à + le → auquel.

### cloze
- sentence: Les questions ___ tu as répondu étaient faciles.
- answer: auxquelles
- en: The questions you answered were easy.
- explain: répondre à + questions (f. pl.) → auxquelles.

### cloze
- sentence: Le restaurant à côté ___ j’habite est excellent.
- answer: duquel
- en: The restaurant next to which I live is excellent.
- explain: à côté de + le → duquel.

### cloze
- sentence: Les amis avec ___ je voyage sont drôles.
- answer: qui
- answer: lesquels
- en: The friends I travel with are funny.
- explain: For people, qui is preferred (lesquels is also correct).

### mcq
- prompt: The film I’m talking about.
- [ ] Le film duquel je parle.
- [x] Le film dont je parle.
- [ ] Le film lequel je parle.
- explain: parler de → dont.

### mcq
- prompt: The boxes in which…
- [ ] Les boîtes dans lesquels…
- [x] Les boîtes dans lesquelles…
- [ ] Les boîtes dans laquelle…
- explain: boîtes: feminine plural.

### transform
- instruction: Join the sentences with a compound relative pronoun.
- source: C’est une idée. Je n’avais jamais pensé à cette idée.
- answer: C’est une idée à laquelle je n’avais jamais pensé

### translate
- en: The table on which I put the book.
- answer: La table sur laquelle j’ai posé le livre
- answer: La table sur laquelle j’ai mis le livre
- answer: La table sur laquelle je pose le livre
- answer: La table sur laquelle je mets le livre
