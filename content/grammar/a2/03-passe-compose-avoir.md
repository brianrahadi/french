## Formation

Present of **avoir** + **past participle**. It translates “I ate”, “I have eaten” and “I did eat”.

|                | manger      |
| -------------- | ----------- |
| j’             | ai mangé    |
| tu             | as mangé    |
| il / elle / on | a mangé     |
| nous           | avons mangé |
| vous           | avez mangé  |
| ils / elles    | ont mangé   |

## Regular past participles

| Infinitive | Participle | Example        |
| ---------- | ---------- | -------------- |
| -er        | -é         | parler → parlé |
| -ir        | -i         | finir → fini   |
| -re        | -u         | vendre → vendu |

## Common irregular participles

| -u                                 | -is / -it            | Others          |
| ---------------------------------- | -------------------- | --------------- |
| avoir → eu                         | prendre → pris       | être → été      |
| boire → bu                         | mettre → mis         | faire → fait    |
| lire → lu                          | dire → dit           | ouvrir → ouvert |
| voir → vu                          | écrire → écrit       | naître → né     |
| pouvoir → pu, vouloir → voulu      | comprendre → compris | mourir → mort   |
| savoir → su, devoir → dû           |                      |                 |
| recevoir → reçu, connaître → connu |                      |                 |

## Negatives and questions

- Je n’ai pas compris. | I didn’t understand.
- Tu as déjà vu ce film ? | Have you already seen this film?
- Avez-vous bien dormi ? | Did you sleep well?

> [!TIP]
> Short adverbs (bien, mal, déjà, encore, beaucoup, trop) go **between** the auxiliary and the participle: *J’ai **bien** mangé.*

## Exercises

### cloze
- sentence: Hier, j’___ un bon film.
- hint: voir
- answer: ai vu
- en: Yesterday I saw a good film.
- explain: voir → vu.

### cloze
- sentence: Nous ___ au restaurant.
- hint: manger
- answer: avons mangé
- en: We ate at the restaurant.
- explain: avons + mangé.

### cloze
- sentence: Tu ___ tes devoirs ?
- hint: finir
- answer: as fini
- en: Did you finish your homework?
- explain: -ir → -i.

### cloze
- sentence: Ils ___ leur maison.
- hint: vendre
- answer: ont vendu
- en: They sold their house.
- explain: -re → -u.

### cloze
- sentence: Elle ___ le bus.
- hint: prendre
- answer: a pris
- en: She took the bus.
- explain: prendre → pris.

### cloze
- sentence: Qu’est-ce que vous ___ ce week-end ?
- hint: faire
- answer: avez fait
- en: What did you do this weekend?
- explain: faire → fait.

### cloze
- sentence: J’___ une lettre à ma grand-mère.
- hint: écrire
- answer: ai écrit
- en: I wrote a letter to my grandmother.
- explain: écrire → écrit.

### transform
- instruction: Make it negative.
- source: J’ai compris.
- answer: Je n’ai pas compris
- explain: ne … pas goes around the auxiliary.

### mcq
- prompt: Past participle of “boire”?
- [ ] buvé
- [x] bu
- [ ] boit
- [ ] bois
- explain: boire → bu.

### order
- en: I have already read this book.
- words: J’ai déjà lu ce livre
- extra: lire
- punct: .

### translate
