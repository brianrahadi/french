## Formation

Take the **ils** form of the present, remove **-ent**, and add **-e, -es, -e, -ent**. For **nous** and **vous**, use the imparfait forms.

|                | parler (ils parlent) | finir (ils finissent) | prendre (ils prennent) |
| -------------- | -------------------- | --------------------- | ---------------------- |
| que je         | parle                | finisse               | prenne                 |
| que tu         | parles               | finisses              | prennes                |
| qu’il / elle   | parle                | finisse               | prenne                 |
| que nous       | parlions             | finissions            | prenions               |
| que vous       | parliez              | finissiez             | preniez                |
| qu’ils / elles | parlent              | finissent             | prennent               |

## Irregular subjunctives

| Verb    | que je…      | que nous… |
| ------- | ------------ | --------- |
| être    | sois         | soyons    |
| avoir   | aie          | ayons     |
| aller   | aille        | allions   |
| faire   | fasse        | fassions  |
| pouvoir | puisse       | puissions |
| savoir  | sache        | sachions  |
| vouloir | veuille      | voulions  |
| falloir | qu’il faille | —         |

## When to use it

The subjunctive appears after **que** when the main clause expresses something **subjective** — not a plain fact:

| Trigger           | Examples                                                 |
| ----------------- | -------------------------------------------------------- |
| Necessity         | il faut que, il est important que                        |
| Wish, will        | vouloir que, souhaiter que, préférer que                 |
| Emotion           | être content / triste / surpris que, avoir peur que      |
| Doubt             | douter que, ne pas penser que                            |
| Some conjunctions | pour que, bien que, avant que, à condition que, sans que |

- Il faut que tu viennes. | You have to come.
- Je veux que vous soyez heureux. | I want you to be happy.
- Je suis content que tu sois là. | I’m glad you’re here.

> [!WARNING]
> Same subject in both clauses → use an infinitive: ~~Je veux que je parte~~ → *Je veux partir*.

## Exercises

### cloze
- sentence: Il faut que tu ___ tes devoirs.
- hint: finir
- answer: finisses
- en: You have to finish your homework.
- explain: ils finissent → finiss- + es.

### cloze
- sentence: Je veux que vous ___ heureux.
- hint: être
- answer: soyez
- en: I want you to be happy.
- explain: être: que vous soyez.

### cloze
- sentence: Il faut que nous ___ ensemble.
- hint: parler
- answer: parlions
- en: We need to talk.
- explain: nous → same as imparfait: parlions.

### cloze
- sentence: Je suis content que tu ___ là.
- hint: être
- answer: sois
- en: I’m glad you’re here.
- explain: Emotion → subjunctive.

### cloze
- sentence: Il est important qu’elle ___ la vérité.
- hint: savoir
- answer: sache
- en: It’s important that she knows the truth.
- explain: savoir → sache.

### cloze
- sentence: Je voudrais que tu ___ le ménage.
- hint: faire
- answer: fasses
- en: I’d like you to do the cleaning.
- explain: faire → fass-.

### cloze
- sentence: Il faut qu’ils ___ le bus de 8 h.
- hint: prendre
- answer: prennent
- en: They have to take the 8 o’clock bus.
- explain: prendre → prenn-.

### cloze
- sentence: Bien qu’il ___ tard, je continue.
- hint: être
- answer: soit
- en: Although it’s late, I’m carrying on.
- explain: bien que always takes the subjunctive.

### mcq
- prompt: I want to leave.
- [ ] Je veux que je parte.
- [x] Je veux partir.
- [ ] Je veux que je pars.
- explain: Same subject → infinitive.

### mcq
- prompt: Which one needs the subjunctive?
- [ ] Je pense que…
- [ ] Je sais que…
- [x] Je doute que…
- [ ] Il est sûr que…
- explain: Doubt triggers the subjunctive; certainty does not.

### translate
- en: You have to come. (tu)
- answer: Il faut que tu viennes
