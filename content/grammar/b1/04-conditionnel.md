## Formation: future stem + imparfait endings

|                | aimer      | être (ser-) | pouvoir (pourr-) |
| -------------- | ---------- | ----------- | ---------------- |
| je             | aimerais   | serais      | pourrais         |
| tu             | aimerais   | serais      | pourrais         |
| il / elle / on | aimerait   | serait      | pourrait         |
| nous           | aimerions  | serions     | pourrions        |
| vous           | aimeriez   | seriez      | pourriez         |
| ils / elles    | aimeraient | seraient    | pourraient       |

> [!TIP]
> Every irregular future stem works here too: *j’irais, je ferais, je viendrais, je voudrais, je devrais…*

## Uses

- Je voudrais un café. | Politeness: I would like a coffee.
- Pourriez-vous m’aider ? | Polite request: Could you help me?
- Tu devrais te reposer. | Advice: You should rest.
- J’aimerais voyager au Japon. | Wish: I’d love to travel to Japan.
- Selon la presse, le ministre démissionnerait. | Unconfirmed news: The minister is reportedly resigning.

## Si clauses

| Type          | si + …    | Main clause               | Example                                          |
| ------------- | --------- | ------------------------- | ------------------------------------------------ |
| Real / likely | présent   | présent, futur, impératif | Si tu veux, on ira à la plage.                   |
| Hypothetical  | imparfait | conditionnel              | Si j’avais de l’argent, j’achèterais une maison. |

> [!WARNING]
> Never put the conditional (or the future) right after **si** meaning “if”: ~~Si j’aurais le temps~~ → *Si j’**avais** le temps*.

The order can be reversed: *J’achèterais une maison si j’avais de l’argent.*

## Exercises

### cloze
- sentence: Je ___ un thé, s’il vous plaît.
- hint: vouloir
- answer: voudrais
- en: I would like a tea, please.
- explain: Polite conditional: je voudrais.

### cloze
- sentence: ___-vous m’aider ?
- hint: pouvoir
- answer: Pourriez
- en: Could you help me?
- explain: vous + pourr- + iez.

### cloze
- sentence: Tu ___ dormir plus.
- hint: devoir
- answer: devrais
- en: You should sleep more.
- explain: Advice: devoir in the conditional.

### cloze
- sentence: Si j’avais le temps, je ___ plus.
- hint: lire
- answer: lirais
- en: If I had time, I would read more.
- explain: si + imparfait → conditionnel.

### cloze
- sentence: Si nous ___ riches, nous voyagerions.
- hint: être
- answer: étions
- en: If we were rich, we would travel.
- explain: After si: imparfait.

### cloze
- sentence: Si tu viens, on ___ au restaurant.
- hint: aller
- answer: ira
- en: If you come, we’ll go to the restaurant.
- explain: si + présent → futur.

### cloze
- sentence: Ils ___ venir s’ils avaient une voiture.
- hint: pouvoir
- answer: pourraient
- en: They could come if they had a car.
- explain: Hypothetical → conditionnel.

### mcq
- prompt: If I were you, I would call her.
- [x] Si j’étais toi, je l’appellerais.
- [ ] Si je serais toi, je l’appellerais.
- [ ] Si j’étais toi, je l’appellerai.
- explain: si + imparfait, conditionnel in the main clause.

### mcq
- prompt: “Le président serait malade” (in a news report) means…
- [ ] The president would be sick.
- [x] The president is reportedly sick.
- [ ] The president will be sick.
- explain: The journalistic conditional marks unconfirmed information.

### transform
- instruction: Make it hypothetical (si + imparfait, conditionnel).
- source: Si j’ai faim, je mange.
- answer: Si j’avais faim, je mangerais

### translate
- en: I would like to live in Paris.
- answer: J’aimerais vivre à Paris
- answer: J’aimerais habiter à Paris
- answer: Je voudrais vivre à Paris
- answer: Je voudrais habiter à Paris
- answer: J’aimerais habiter Paris
