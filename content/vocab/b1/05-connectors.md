---
id: b1-connectors
title: Linking words
titleFr: Les connecteurs
---

| French      | English                    | Type | Example                                            | Translation                                   | Note                                            |
| ----------- | -------------------------- | ---- | -------------------------------------------------- | --------------------------------------------- | ----------------------------------------------- |
| parce que   | because                    | conj | Je reste parce qu'il pleut.                        | I'm staying because it's raining.             |                                                 |
| car         | because, for               | conj | Il est absent, car il est malade.                  | He's absent, as he's ill.                     | More formal than parce que; never at the start. |
| donc        | so, therefore              | conj | Je pense, donc je suis.                            | I think, therefore I am.                      |                                                 |
| alors       | so, then                   | adv  | Alors, on y va ?                                   | So, shall we go?                              |                                                 |
| pourtant    | yet, and yet               | adv  | Il est riche, et pourtant il n'est pas heureux.    | He's rich, and yet he isn't happy.            |                                                 |
| cependant   | however                    | adv  | C'est une bonne idée ; cependant, elle coûte cher. | It's a good idea; however, it's expensive.    |                                                 |
| ensuite     | then, next                 | adv  | D'abord on mange, ensuite on sort.                 | First we eat, then we go out.                 |                                                 |
| d'abord     | first, at first            | adv  | D'abord, lisez le texte.                           | First, read the text.                         |                                                 |
| enfin       | finally; well…             | adv  | Enfin, tu es là !                                  | At last, you're here!                         |                                                 |
| par exemple | for example                | expr | Des fruits, par exemple des pommes.                | Fruit, for example apples.                    |                                                 |
| en effet    | indeed                     | expr | En effet, tu avais raison.                         | Indeed, you were right.                       |                                                 |
| grâce à     | thanks to                  | prep | J'ai réussi grâce à toi.                           | I succeeded thanks to you.                    | Positive cause.                                 |
| à cause de  | because of                 | prep | Le vol est annulé à cause de la neige.             | The flight is cancelled because of the snow.  | Usually a negative cause.                       |
| par contre  | on the other hand, however | expr | J'aime le thé ; par contre, je déteste le café.    | I like tea; on the other hand, I hate coffee. |                                                 |
| sinon       | otherwise, or else         | conj | Dépêche-toi, sinon on va rater le train.           | Hurry up, otherwise we'll miss the train.     |                                                 |
| lorsque     | when                       | conj | Lorsque je suis arrivé, tout le monde dormait.     | When I arrived, everyone was asleep.          |                                                 |
| pendant que | while                      | conj | Il cuisine pendant que je fais la vaisselle.       | He cooks while I do the dishes.               |                                                 |
| depuis      | since, for                 | prep | J'habite ici depuis 2019.                          | I've lived here since 2019.                   |                                                 |
| il y a      | ago                        | prep | Je suis arrivé il y a trois jours.                 | I arrived three days ago.                     |                                                 |
| dès que     | as soon as                 | conj | Appelle-moi dès que tu arrives.                    | Call me as soon as you arrive.                |                                                 |
| avant de    | before (+ infinitive)      | prep | Lave-toi les mains avant de manger.                | Wash your hands before eating.                |                                                 |
| afin de     | in order to                | prep | Je me lève tôt afin de courir.                     | I get up early in order to run.               |                                                 |
| au lieu de  | instead of                 | prep | Au lieu de te plaindre, aide-moi !                 | Instead of complaining, help me!              |                                                 |
| même si     | even if                    | conj | Je viendrai, même s’il pleut.                      | I'll come, even if it rains.                  |                                                 |
