id: b2-connectors
title: Advanced connectors
titleFr: Connecteurs avancés
---

| French            | English                               | Type | Example                                             | Translation                                            | Note                                                     |
| ----------------- | ------------------------------------- | ---- | --------------------------------------------------- | ------------------------------------------------------ | -------------------------------------------------------- |
| bien que          | although (+ subjunctive)              | conj | Bien qu'il soit tard, je continue.                  | Although it's late, I'm carrying on.                   |                                                          |
| à moins que       | unless (+ subjunctive)                | conj | On ira à la plage, à moins qu’il (ne) pleuve.       | We'll go to the beach, unless it rains.                |                                                          |
| pourvu que        | provided that; let’s hope             | conj | Pourvu qu'il fasse beau demain !                    | Let's hope it's nice tomorrow!                         |                                                          |
| de sorte que      | so that                               | conj | Parle fort, de sorte que tout le monde entende.     | Speak loudly so that everyone can hear.                |                                                          |
| si bien que       | so much so that, with the result that | conj | Il a plu, si bien que le match a été annulé.        | It rained, so the match was cancelled.                 |                                                          |
| néanmoins         | nevertheless                          | adv  | C'est risqué ; néanmoins, je le ferai.              | It's risky; nevertheless, I'll do it.                  |                                                          |
| toutefois         | however                               | adv  | Toutefois, il reste un problème.                    | However, one problem remains.                          |                                                          |
| en revanche       | on the other hand                     | expr | Le film est long ; en revanche, il est passionnant. | The film is long; on the other hand, it is gripping.   |                                                          |
| or                | yet, now (logical)                    | conj | Il devait venir ; or, il n'est pas là.              | He was supposed to come; yet he isn't here.            |                                                          |
| d'ailleurs        | besides, moreover                     | adv  | D'ailleurs, je n'avais pas faim.                    | Besides, I wasn't hungry.                              |                                                          |
| quant à           | as for                                | prep | Quant à moi, je reste.                              | As for me, I'm staying.                                |                                                          |
| en outre          | furthermore                           | adv  | En outre, le prix a augmenté.                       | Furthermore, the price has gone up.                    |                                                          |
| par ailleurs      | moreover; otherwise                   | adv  | Par ailleurs, il faut noter que…                    | Moreover, it should be noted that…                     |                                                          |
| faute de          | for lack of                           | prep | Faute de temps, on a annulé.                        | For lack of time, we cancelled.                        |                                                          |
| compte tenu de    | given, in view of                     | prep | Compte tenu de la situation…                        | Given the situation…                                   |                                                          |
| étant donné que   | given that                            | conj | Étant donné que tu es là, aide-moi.                 | Given that you're here, help me.                       |                                                          |
| vu que            | seeing that                           | conj | Vu qu'il pleut, on reste.                           | Seeing that it's raining, we're staying.               |                                                          |
| dans la mesure où | insofar as                            | conj | Dans la mesure où c’est possible…                   | Insofar as it is possible…                             |                                                          |
| malgré            | despite                               | prep | Malgré la pluie, on est sortis.                     | Despite the rain, we went out.                         | Followed by a noun; bien que + subjunctive for a clause. |
| afin que          | so that (+ subjunctive)               | conj | Je répète afin que tu comprennes.                   | I'm repeating so that you understand.                  |                                                          |
| de peur que       | for fear that (+ subjunctive)         | conj | Il se tait de peur qu’on se moque de lui.           | He keeps quiet for fear that people will laugh at him. |                                                          |
| à condition que   | on condition that (+ subjunctive)     | conj | Je viens, à condition que tu conduises.             | I'll come, on condition that you drive.                |                                                          |
