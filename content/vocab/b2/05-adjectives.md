title: Precise adjectives
titleFr: Adjectifs précis
---

| French        | English                   | Type            | Example                               | Translation                      | Note                                    |
| ------------- | ------------------------- | --------------- | ------------------------------------- | -------------------------------- | --------------------------------------- |
| indispensable | essential                 | adj             | Ton aide est indispensable.           | Your help is essential.          |                                         |
| pertinent     | relevant                  | adj:pertinente  | Une remarque très pertinente.         | A very relevant remark.          |                                         |
| efficace      | effective, efficient      | adj             | Une méthode efficace.                 | An effective method.             |                                         |
| fiable        | reliable                  | adj             | Cette source est fiable.              | This source is reliable.         |                                         |
| durable       | sustainable, lasting      | adj             | Le développement durable.             | Sustainable development.         |                                         |
| flou          | blurry, vague             | adj:floue       | Ses explications sont floues.         | His explanations are vague.      |                                         |
| néfaste       | harmful                   | adj             | Un effet néfaste sur la santé.        | A harmful effect on health.      |                                         |
| bénéfique     | beneficial                | adj             | Le sport est bénéfique pour le moral. | Exercise is good for morale.     |                                         |
| ambigu        | ambiguous                 | adj:ambiguë     | Une réponse ambiguë.                  | An ambiguous answer.             |                                         |
| exigeant      | demanding                 | adj:exigeante   | Un professeur exigeant.               | A demanding teacher.             |                                         |
| épuisé        | exhausted                 | adj:épuisée     | Je suis épuisée après cette semaine.  | I'm exhausted after this week.   |                                         |
| bouleversé    | deeply moved, shaken      | adj:bouleversée | Il était bouleversé par la nouvelle.  | He was shaken by the news.       |                                         |
| soulagé       | relieved                  | adj:soulagée    | Je suis soulagé que tu sois là.       | I'm relieved you're here.        |                                         |
| méfiant       | wary, suspicious          | adj:méfiante    | Les chats sont méfiants.              | Cats are wary.                   |                                         |
| inédit        | unprecedented; unreleased | adj:inédite     | Une situation inédite.                | An unprecedented situation.      |                                         |
| sensible      | sensitive                 | adj             | Elle est très sensible.               | She's very sensitive.            | False friend: "sensible" = raisonnable. |
| actuel        | current, present-day      | adj:actuelle    | La situation actuelle.                | The current situation.           | False friend: "actual" = réel.          |
| éventuel      | possible, potential       | adj:éventuelle  | En cas de problème éventuel…          | In case of any possible problem… | False friend: "eventual" = final.       |
| susceptible   | touchy; likely (to)       | adj             | Ne sois pas si susceptible !          | Don't be so touchy!              |                                         |
| conscient     | aware, conscious          | adj:consciente  | Je suis conscient du problème.        | I'm aware of the problem.        |                                         |
